## 翻訳したもの

README、スキルの説明と実行例、ソースコードのコメント、CLI の表示・エラーメッセージ、単体テスト名と検査失敗時の説明、P0 ケースの表示名を日本語化しています。

API 用の質問、ID、既定値、分岐、正規表現、実行方式は変更していません。表示メッセージを外部で文字列比較している独自の処理がある場合、その部分は日本語化の影響を受けます。機械向けの `status`、`verdict`、`kind`、イベント名は維持しています。

README とスキルには、Windows 対応が未完了であること、dry-run でも観測・通信・保存があること、Policy が安全の保証ではないことを明記しています。上流の「英語が最も正確」「副作用がないアプリ」という説明は、未検証の保証として読まれない表現にしています。

## あえて維持する文字列

中国語 UI を再現する `fixtures/ax/` のスナップショットとテスト内の画面文字列は原文のままです。これらを日本語に置き換えると、中国語の解析不具合が再発しても検出できなくなります。

`ROLE_ALIASES` の中国語ロール、`SENSITIVE_LABEL_PATTERNS` の中国語検出語、候補抽出の照合語もそのままです。これらは説明ではなくプログラムの入力仕様です。日本語のロールや危険語への対応強化は、別の機能変更としてテスト付きで検討します。

Jev へ渡す英語の質問文・選択肢の説明も維持します。表示の日本語化と、モデルの判断に使う質問の変更を同時に行わないためです。日本語 UI 対応や多言語の判断精度が確認されたことを意味しません。
