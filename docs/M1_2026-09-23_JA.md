# M1：実Jev接続前の実装・検証記録

2026-09-23。基準 `9b841a062ee8078fa6ce2d102bc78d3e61378f8a`。この記録はWindows側で実施した作業の要約であり、画面・実機ID・個人設定・秘密値は保存しない。実Jev APIは0回、キーの存在確認や読取りも0回。

## 実装した境界

- `scripts/windows-sky-adapter.mjs`：公式のsky clientを注入し、一覧、完全一致の対象選択、再列挙、状態取得を行う。曖昧・消失・窓不一致・期限切れ・観測失敗を区別する。観測ID、時刻、30秒の期限、取得元、窓と画像の参照を保持する。画像のdata URLは結果に含めない。トップレベルでは観測・起動・通信・秘密読込を行わない。
- `accessibility:null`は`unavailable`。文字列のtreeが返っても、Windows実測で形式を確認するまでは要素パーサーを実装しない。`empty_tree`と`unsupported_format`を区別し、候補itemsが空でも「画面に要素がない」とは結論しない。
- `scripts/jev-decide.mjs`：正確な宛先 `https://api.typesafe.ai/v1/systemone` を固定、redirectを拒否、cookieを付けない。モデルを`jev-1.13.0`へ固定。要求16KiB、応答64KiBを上限とし、fetch開始から本文読込・検証まで既定10秒。自動再試行なし。Choice/Noulの型、候補、確率範囲、分布、選択整合性、usage、モデルを検査する。エラー本文、キー、生応答は返さない。ScoreはM1対象外。
- 標準fetchは`allowNetwork:true`が必要。キー自動読込は別に`allowSecretRead:true`が必要。`loadApiKey()`単独も既定では拒否する。これらのフラグは人間の許可を代替しない。注入transport・driver・時計・結果確認を行う呼出し側コードは信頼境界の内側であり、サンドボックスではない。
- `scripts/operation-choice.mjs`：対象・操作・準備済み引数を一つの操作IDへ結び付け、候補セットIDと観測IDも選択結果へ保持する。別セットで同じIDを再利用しても、古い回答は実行できない。NONE / REOBSERVE / REASONING / VISION / ASK_USERは非実行の返却だけ。引き継ぎ先の自動起動や返答の自動実行なし。
- `scripts/guarded-key-session.mjs`：試験用Windows電卓だけに限定。明示した数字・四則演算・確定キーの部分集合、窓、回数、期限を固定。prepare→refresh→画像を確認→dispatch→画像を確認→verifyの順。APIが返した実物のWindowを再利用し、操作用のWindowを捏造しない。結果不明は再送せず停止し、同じclientの新規sessionも拒否する。同一モジュール／client内の排他であり、他プロセス・人間・別ツールをロックできるという意味ではない。

## 旧経路の変更と互換性

旧`runTask`の実操作は、独立したtarget/action、選択後のresources置換、既定Return、無制限の再呼出し等を持っていた。この入口をWindows向けに補修して二つの実行基盤を維持せず、`dryRun:false`ではdriver呼出しより前に`legacy_execution_disabled`を返す。AX解析・候補抽出・一回の読み取りプレビューは残した。モデルのdoneは`done_proposed`であり成功ではない。旧プレビューのファイルトレースと任意文字列のemitを廃止し、返却項目を固定した。

旧CLI・P0は通信許可を渡さないため実Jevへ接続しない。P0は旧評価資料でありM1の実API入口には使用しない。旧スキルをインストールする作業は行っていない。

既存22テストのうち、旧実行ループへ依存するケースを、新しい実行境界・旧入口が操作しないことの試験へ置き換えた。日本語／中国語AX・CRLF・候補抽出は保持。完了推定を成功扱いにする期待値は修正した。テスト数だけを維持するために不正な挙動を残していない。

## 最小の使い方

オフライン例（通信・GUI実行なし）：

```powershell
npm test
node examples/m1-offline.mjs
```

読み取り例は現在のComputer Useスキルを読んだnode_replで実行する。アプリは許可されたものを用意し、旧IDを貼り付けない。

```js
if (!globalThis.sky) globalThis.sky = (await import('@oai/sky')).sky;
const {pathToFileURL} = await import('node:url');
const {createWindowsSkyAdapter} = await import(pathToFileURL(`${nodeRepl.cwd}/scripts/windows-sky-adapter.mjs`).href);
const adapter = createWindowsSkyAdapter(sky);
const selection = await adapter.selectWindow({app: 'Microsoft.WindowsCalculator_8wekyb3d8bbwe!App'});
const observed = await adapter.observe(selection);
nodeRepl.write(JSON.stringify({source:observed.source, accessibility:observed.accessibility.status}));
```

固定操作例は試験用電卓が0を表示していることを確認してから、次のセルでprepareとrefreshを行う。

```js
const {createCalculatorKeySession} = await import(pathToFileURL(`${nodeRepl.cwd}/scripts/guarded-key-session.mjs`).href);
const {interpretOperationChoice} = await import(pathToFileURL(`${nodeRepl.cwd}/scripts/operation-choice.mjs`).href);
const session = createCalculatorKeySession({sky,adapter,selection,allowedKeys:['2'],maxActions:1});
const batch = session.prepare(observed,[{id:'A1',key:'2',description:'試験用電卓に数字2を入力する'}]);
const fresh = await session.refresh(batch);
const fixedChoice = interpretOperationChoice({choice:'A1',confidence:1},batch.operations);
```

refreshの画像が意図した試験用電卓・開始状態であることを確認してから、別セルで一回だけdispatchする。Jevにこの確認フラグを決めさせない。

```js
const result = await session.dispatch(batch,fixedChoice,{observationId:fresh.id,confirmed:true});
nodeRepl.write(result.status);
```

表示2を確認してから次セルで`session.verify(result,{observationId:result.observation.id,passed:true})`、その後`session.close()`。無変化なら`passed:false`。結果確認前に画像が古くなった場合は、全体期限と観測回数の範囲で`result = await session.refreshResult(result)`として読み取りだけを更新できる（その用途ではresultをletで宣言する）。unknownなら同じ操作を再送せず、外側へ引き継ぐ。参照期限切れ・session期限切れを回避するために期限を無制限に延ばさない。

## 実Jev接続前にユーザーへ示す案

初回は`examples/m1-offline.mjs`と同じ人工タスク・説明文のみを送る。SyntheticCalculatorの表示0、目標Enter digit 2、用意した操作A1と非実行の5選択肢。実画面・ウィンドウタイトル・個人パス・画像・既存文書は送らない。回答を記録するだけでGUIは実行しない。

提案は1要求、再試行0、JSON全体2KiB以内、期限10秒、予算枠$0.01。当日の文書料金では十分小さい見込みだが、金額のハード上限はこのclientが保証するものではない。実接続直前に料金・送信サイズを確認し、上限の扱いを合意する。キーの設定済み／未設定もまだ確認していない。

承認後にユーザーがプロジェクト直下`.env.local`へ`TYPESAFE_API_KEY=...`をローカル編集で設定するか、当該プロセスの環境変数を使う。会話・PR・コマンド履歴に値を貼らない。接続コードには`allowNetwork:true`と、ローカル読込を許可する場合だけ`allowSecretRead:true`を明示する。M1はこの境界で終了する。
